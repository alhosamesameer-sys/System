# أرصد | ARSAD

تطبيق Android محلي لإدارة المبيعات والأصناف والصندوق والشبكة والمردودات والتقارير.

## المبدأ الأمني
- لا يوجد backend أو API أو تسجيل دخول خارجي.
- لا يطلب التطبيق صلاحية INTERNET.
- تخزين البيانات في SQLite على الجهاز.
- كل القيم المالية تحفظ بالهللات كأعداد صحيحة.
- عمليات الفاتورة والمردود تتم داخل SQLite transaction.

## التقنية
Flutter / Dart / Material 3 / SQLite.

## التشغيل
1. ثبّت Flutter SDK وAndroid SDK.
2. من مجلد arsad نفّذ flutter pub get.
3. نفّذ flutter run.
4. للبناء: flutter build apk --release.

## حالة التنفيذ
هذا المستودع يبدأ الآن بالهيكل الأساسي وقاعدة البيانات المحلية. لا تعتبر النسخة مكتملة أو جاهزة للنشر قبل إكمال وربط الشاشات والطباعة والباركود والنسخ الاحتياطي واجتياز الاختبارات الموضحة في خطة التطوير.
