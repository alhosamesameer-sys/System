# أرصد | ARSAD

تطبيق محاسبة ومبيعات Android محلي باستخدام Flutter وSQLite.

## بيانات الدخول الافتراضية
- اسم المستخدم: `sameer`
- كلمة المرور: `123456`

غيّر كلمة المرور قبل إدخال بيانات حقيقية.

## التشغيل
```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

## بناء APK
```bash
flutter build apk --release
```
بعد نجاح مهمة GitHub Actions المسماة **ARSAD Android Build** يمكن تنزيل APK من قسم Artifacts.

## الخصوصية
لا توجد خدمة خادم أو API أو تحليلات. لا يطلب التطبيق إذن INTERNET في Manifest الأساسي. قاعدة البيانات محلية. الكاميرا مخصصة لمسح الباركود، وأذونات Bluetooth محضرة للاتصال المحلي.

## حالة التنفيذ
تم توصيل تسجيل الدخول المحلي، الأصناف، المبيعات والفواتير، قيود الصندوق والشبكة، المردودات الجزئية، التقارير الأولية والنسخ الاحتياطي JSON. الطباعة الحالية عبر Android Print/PDF؛ دعم ESC/POS Bluetooth المباشر واختبار الطابعات الفعلية والتحقق الشامل على جهاز Android ما زالت غير مكتملة.
