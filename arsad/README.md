# أرصد | ARSAD

تطبيق Android للمبيعات والمحاسبة المحلية باستخدام Flutter وDart وSQLite.

## الدخول الافتراضي
- اسم المستخدم: sameer
- كلمة المرور: 123456

غيّر كلمة المرور من الإعدادات قبل إدخال بيانات المتجر الحقيقية.

## التشغيل لأول مرة
من مجلد arsad نفّذ:
flutter create --platforms=android --org com.arsad --project-name arsad .
flutter pub get
flutter analyze
flutter test
flutter run

## بناء APK
flutter build apk --release

أو نزّل Artifact باسم arsad-release-apk من صفحة GitHub Actions بعد نجاح مهمة البناء.

## الوحدات
- دخول محلي باسم مستخدم وكلمة مرور.
- الأصناف والباركود وإدارة المخزون الاختيارية.
- مبيعات متعددة الأصناف، نقد/شبكة، وتعديل سعر الوحدة للفاتورة.
- فواتير ومردودات جزئية/كاملة بقيود مترابطة.
- الصندوق والشبكة: أرصدة افتتاحية، إيداعات، سحوبات، مصروفات ورسوم بنكية.
- تقارير بفترات زمنية مع صافي المبيعات والحركات.
- نسخ احتياطي JSON واستعادة داخل معاملة SQLite.
- طباعة Android PDF وطباعة ESC/POS عبر Bluetooth Classic لطابعات سبق إقرانها.

## الخصوصية والعمل دون إنترنت
لا يستخدم التطبيق خادماً أو API أو تحليلات أو تسجيل دخول خارجي. قاعدة البيانات داخل مساحة التطبيق الخاصة. أذونات الكاميرا وBluetooth تستخدم فقط عند طلب الوظيفة. إعدادات البناء تزيل صلاحية INTERNET من التطبيق.

## ملاحظات مهمة
- الطباعة الحرارية تعتمد على توافق الطابعة مع Bluetooth Classic وESC/POS. بعض الطابعات تحتاج ضبط ترميز عربي خاص بها؛ اختبرها فعلياً قبل الاستخدام التجاري.
- نسخة PDF تعتمد على دعم الخطوط العربية في عارض/خدمة الطباعة على الجهاز.
- يجب إجراء اختبار ميداني على الهاتف والطابعة قبل اعتماد التطبيق في المحاسبة اليومية.
